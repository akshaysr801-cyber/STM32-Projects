# STM32 Projects

A collection of my STM32 embedded firmware development projects using Embedded C.

This repository documents my learning and practical implementation of STM32 microcontrollers, GPIO drivers, peripheral interfacing, and embedded firmware development.

## Hardware Platform

- STM32 Nucleo Development Board
- ARM Cortex-M Microcontrollers

## Development Tools

- STM32CubeIDE
- Embedded C
- STM32 HAL
- CMSIS
- Git and GitHub
